## 用户角色 [#用户角色]

| 角色  | 描述                  |
| --- | ------------------- |
| 车主  | 拥有车辆并可以通过 App 管理的用户 |
| 乘客  | 通过共享授权使用车辆服务的用户     |
| 管理员 | 管理车辆权限和服务的后台用户      |

## 用户故事列表 [#用户故事列表]

<Accordions>
  <Accordion title="US-001: 实时查看车辆状态">
    **作为** 车主\
    **我希望** 能够实时查看车辆的电量、里程和位置\
    **以便** 随时了解车辆状况

    **验收标准：**

    * 首页展示车辆状态卡片
    * 数据刷新频率 ≤ 5 秒
    * 离线车辆显示最后在线时间
  </Accordion>

  <Accordion title="US-002: 远程锁车">
    **作为** 车主\
    **我希望** 能够通过 App 远程锁车/解锁\
    **以便** 忘记锁车时无需返回车辆

    **验收标准：**

    * 执行结果在 10 秒内反馈
    * 失败时提供原因
    * 有防误触确认机制
  </Accordion>
</Accordions>
