## F-001: 用户认证 [#f-001-用户认证]

<Callout type="info">
  优先级: P0 | 状态: 已确认
</Callout>

**功能描述：** 用户通过手机号或邮箱注册/登录系统。

**前置条件：** 用户拥有有效的手机号或邮箱地址。

**后置条件：** 用户获得有效的访问令牌。

**正常流程：**

1. 用户输入手机号/邮箱
2. 系统发送验证码
3. 用户输入验证码
4. 系统验证并返回令牌

**异常流程：**

* 验证码错误超过 5 次，锁定 30 分钟
* 网络异常时提示重试

## F-002: 车辆绑定 [#f-002-车辆绑定]

<Callout type="warn">
  优先级: P0 | 状态: 开发中
</Callout>

**功能描述：** 用户通过 VIN 码或扫码绑定车辆。

**业务规则：**

* 一个用户最多绑定 5 辆车
* 一辆车最多同时被 3 个用户绑定
* 绑定需要车主授权

## F-003: 数据同步 [#f-003-数据同步]

**功能描述：** 车辆数据与云端实时同步。

**技术规格：**

| 参数   | 值                    |
| ---- | -------------------- |
| 同步协议 | MQTT over WebSocket  |
| 数据格式 | Protocol Buffers     |
| 同步频率 | 5 秒 (状态) / 1 分钟 (位置) |
| 离线缓存 | 7 天                  |
