# 模块列表 (/docs/frs/module-list)





# 模块列表 [#模块列表]

## 核心模块 [#核心模块]

### 用户管理模块 [#用户管理模块]

| 功能   | 输入           | 输出           |
| ---- | ------------ | ------------ |
| 注册   | 手机号、验证码      | 用户 ID        |
| 登录   | 手机号+密码 / 验证码 | Access Token |
| 权限管理 | 用户 ID、角色     | 权限配置         |

### 车辆管理模块 [#车辆管理模块]

| 功能   | 输入          | 输出     |
| ---- | ----------- | ------ |
| 绑定车辆 | VIN 码、车主授权码 | 绑定记录   |
| 解绑车辆 | 车辆 ID       | 解绑确认   |
| 状态查询 | 车辆 ID       | 实时状态数据 |

### 远程控制模块 [#远程控制模块]

* 锁车/解锁
* 空调开关及温度设置
* 充电管理（开始/停止/预约）
* 车窗控制
* 寻车功能
